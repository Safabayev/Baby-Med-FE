# Заявки с сайта в Google Таблицу

Форма записи (`/zapis` и блок на главной) отправляет заявку на `/api/booking`.
Роут проверяет данные и передаёт их в Google Таблицу через Apps Script.
Все заявки складываются в один лист «Заявки» — его можно открыть как обычную
таблицу и скачать в `.xlsx` (Файл → Скачать → Microsoft Excel).

Пока переменные окружения не заданы, форма честно скажет посетителю, что
отправить не получилось, и покажет телефон клиники — заявки не теряются молча.

## 1. Создать таблицу и скрипт

1. Создайте новую Google Таблицу (например, «Baby Med — заявки с сайта»).
2. В ней: **Расширения → Apps Script**.
3. Удалите содержимое `Код.gs` и вставьте туда файл [`booking-sheet.gs`](./booking-sheet.gs).
4. В строке `var SHARED_TOKEN = '...'` замените заглушку на собственный
   секрет — любую длинную случайную строку. Она нужна, чтобы в таблицу не мог
   писать посторонний, нашедший URL. Сохраните проект.

## 2. Развернуть как веб-приложение

1. **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. «Запуск от имени» — **От моего имени**.
4. «У кого есть доступ» — **У всех** (иначе сайт не сможет достучаться;
   защита обеспечивается токеном из шага 1).
5. Нажмите «Развернуть», подтвердите доступ к таблице и скопируйте
   **URL веб-приложения** — он вида `https://script.google.com/macros/s/…/exec`.

Проверить развёртывание можно, открыв этот URL в браузере: должен вернуться
`{"ok":true,"service":"baby-med-booking"}`.

## 3. Прописать переменные окружения на Netlify

**Site configuration → Environment variables**, добавить две переменные:

| Переменная | Значение |
| --- | --- |
| `BOOKING_SHEET_WEBHOOK_URL` | URL веб-приложения из шага 2 |
| `BOOKING_SHEET_TOKEN` | тот же секрет, что в `SHARED_TOKEN` |

После этого запустите передеплой сайта — переменные подхватываются на сборке.

Для локальной разработки те же две строки положите в `.env.local` в корне
проекта (файл не коммитится):

```
BOOKING_SHEET_WEBHOOK_URL=https://script.google.com/macros/s/…/exec
BOOKING_SHEET_TOKEN=ваш-секрет
```

## Что попадает в таблицу

| Колонка | Откуда |
| --- | --- |
| Дата заявки | момент отправки, время ташкентское |
| Имя | обязательное поле формы |
| Телефон | обязательное, приводится к виду `+998XXXXXXXXX` |
| Направление | обязательный выбор из списка направлений клиники |
| Желаемая дата | необязательное поле |
| Комментарий | необязательное поле, до 500 символов |
| Язык сайта | русская или узбекская версия сайта |

## Если понадобится сменить хранилище

Вся отправка наружу изолирована в `src/app/api/booking/route.ts`. Проверка
полей живёт отдельно, в `src/lib/booking.ts`, и используется и формой, и
роутом — так что заменить Google Таблицу на CRM, базу или Telegram можно,
не трогая форму и валидацию.
